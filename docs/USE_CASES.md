# 使用场景

> 本文记录其他开源模组中与 Perspective API 相关的特性，以及目前未必存在于真实模组中的假想特性。
>
> - 不表示 Perspective API 的当前设计已经适合这些模组
> - 不表示这些模组应当使用 Perspective API
> - 真实模组的描述以标题所链接的官方仓库为主要依据

## 假想的模组特性

本节中的特性不对应特定的真实模组。

### 潜望镜

- 玩家使用潜望镜物品时进入潜望镜视角
- 潜望镜视角可以使用与玩家当前视角不同的相机位置、旋转和 FOV
- 玩家停止使用潜望镜时退出潜望镜视角，并恢复使用潜望镜前的视角

### 自定义第三人称视角

- 提供与 Leawind's Third Person 类似的可配置第三人称视角
- 默认不提供预设视角，或者只提供一个默认预设
- 玩家可以创建同一种第三人称视角的多个预设
- 每个预设分别保存相机距离、位置偏移、旋转方式、FOV 等参数
- 玩家可以在自己创建的预设之间切换

### 锁定视角

- 玩家按下特定按键时，在画面内寻找可攻击的实体
- 将画面中距离准星最近的符合条件的实体设为锁定目标
- 存在锁定目标时持续控制视角，使目标实体保持在画面中
- 当前视角不能通过鼠标转动时停止锁定控制，并向玩家显示说明文本
- 当目标消失、死亡、超出锁定距离或玩家再次按下相应按键时清除锁定目标

### 正交俯视视角

- 保持相机与玩家实体的相对位置不变，将相机固定空中，俯视玩家实体
- 使用正交视角
- 在画面上显示光标，玩家可以用鼠标点击地面，让玩家实体自动前往该地点
- 当光标与玩家实体间的距离增大时，适当增加正交视角的画面高度

## 第三人称相机

### [Shoulder Surfing Reloaded](https://github.com/Exopandora/ShoulderSurfing)

- 将相机放置在玩家肩后，并可以通过快捷键移动相机或切换左右肩位
- 提供相机与玩家移动方向解耦的第三人称视角和自由观察
- 提供自适应或动态准星的位置修正
- 当玩家模型遮挡视线时，自适应地降低玩家模型透明度

### [Leawind's Third Person](https://github.com/Leawind/Third-Person)

- 允许在不转动玩家身体的情况下自由旋转第三人称视角
- 允许用鼠标调整相机偏移和距离，并快速切换左、中、右构图
- 根据使用中的物品自动进入瞄准模式，并允许用配置规则扩展其他模组的物品
- 修正第三人称瞄准时的射击方向，并在玩家遮挡视线时降低玩家模型透明度
- 在第一人称和第三人称之间平滑切换

## 传送、回放与电影镜头

### [Grand Teleport](https://github.com/hookuru/GrandTeleport)

- 在传送开始后让相机离开玩家，经过多个可配置高度的拉远阶段升到高空
- 需要知道在上一帧中最终用于渲染的相机状态，以便实现自定义的平滑过渡
- 在条件允许时让高空相机在起点和终点之间移动，并在目的地附近回到玩家
- 可以在转场期间阻止玩家的移动和相机输入
- 可以为跨维度传送启用相机转场

### [ReplayMod](https://github.com/ReplayMod/ReplayMod)

- 在回放中使用可自由移动或跟随实体的相机
- 位置关键帧保存相机的位置、yaw、pitch 和 roll，并可使用线性或三次样条插值生成相机路径
- 时间关键帧独立控制回放时间与相机路径时间的对应关系
- 可以将相机路径渲染为普通、立体、立方体或等距柱状投影视频

### [Flashback](https://github.com/Moulberry/Flashback)

- 记录并回放 Minecraft 游戏过程
- 在回放中提供用于制作电影镜头的相机编辑功能

## 相机旋转与晃动

### [Do a Barrel Roll](https://codeberg.org/enjarai/do-a-barrel-roll)

- 在满足客户端配置和服务端下发配置等启用条件时，将本地玩家的鞘翅飞行状态标记为滚转状态
- 滚转期间拦截原版鼠标视角移动输入，不再让原版直接按照二维 yaw、pitch 方式应用同一份输入，而是先在当前三维姿态的局部轴上计算 pitch、yaw 和 roll 增量
- 默认将鼠标纵向移动映射为 pitch、鼠标横向移动映射为 roll，并使用默认绑定到 A、D 的独立按键控制 yaw；可以交换 yaw 与 roll 的映射、反转 pitch，或使用动量式鼠标控制
- 输入增量依次经过轴映射、按键输入、灵敏度、控制面效率、平滑、倾侧和自动回正等可配置处理，再生成新的三维姿态
- 将新姿态中的 yaw 和 pitch 通过原版实体视角转动逻辑写回玩家实体，同时把原版实体没有的 roll 作为独立字段保存在玩家实体上
- 原版 Camera 仍根据活动 camera entity 的位置、yaw 和 pitch 建立基础状态；模组在相机的不同原版旋转分支中合成该实体经过帧插值的 roll，不接管相机位置或 FOV
- 玩家退出滚转状态后将实体 roll 重置为零，并让 Camera 中最后采用的 roll 逐步衰减，从而平滑恢复水平画面
- 在服务端支持同步时发送玩家的滚转状态和 roll，使其他客户端能够插值远端玩家的 roll，并在玩家模型渲染中表现对应滚转

### [Camera Overhaul](https://github.com/Mirsario/Minecraft-CameraOverhaul)

- 根据前进、后退、横移、转向、跳跃和下落等运动为相机添加 pitch 或 roll
- 根据玩家当前处于步行、疾跑、游泳、飞行、骑乘载具或骑乘生物等状态切换效果参数，并在参数之间平滑过渡
- 对相机的 yaw 和 pitch 变化进行平滑
- 在玩家停止操作一段时间后添加逐渐出现的相机摇摆
- 叠加带有持续时间和衰减的相机震动；震动可以绑定世界位置，并根据相机与震源的距离减弱

## FOV

### [Zoomify](https://github.com/isXander/Zoomify)

- 在保持相机位置和旋转不变的情况下缩小 FOV。
- 提供平滑缩放、滚轮调整倍率和缩放时的鼠标灵敏度调整。

## 取景与拍照

### [Photography](https://github.com/BlouFlin/Photography)

- 使用相机物品时打开仅限第一人称的取景器，并隐藏普通 HUD
- 使用鼠标滚轮调整 FOV，同时按缩放倍率调整鼠标灵敏度
- 从客户端主渲染目标截取取景器中的画面，并将照片转换为地图图像

### [Exposure](https://github.com/mortuusars/Exposure)

- 为手持相机提供第一人称取景器，并通过镜头的焦距范围限制和平滑调整 FOV
- 缩放时按当前 FOV 调整鼠标灵敏度，退出取景器后平滑恢复原 FOV
- 提供正面第三人称自拍模式，可在有限范围内独立调整自拍相机的 pitch 和 yaw，并限制第三人称相机距离
- 使用相机架拍摄时将相机实体切换为相机架，停止控制后切回玩家
- 拍摄时从客户端渲染画面取图，并可临时切换相机实体、相机模式、FOV、后处理、滤镜和 gamma

## 自由相机与碰撞

### [Camera Utils](https://github.com/henkelmax/camera-utils)

- 提供按键缩放和滚轮动态缩放，并支持缩放动画
- 将相机固定在当前世界位置和旋转，同时允许玩家继续移动和转向；也可返回上一次固定的机位
- 调整普通第三人称相机距离，最多可以将相机移到距离玩家 100 方块的位置
- 提供两个可配置的第三人称相机预设，分别设置相对于玩家的位置偏移、pitch 和前后朝向
- 提供可配置的电影相机控制和移动平滑
- 相机固定时停用原版视角晃动

### [Freecam](https://github.com/MinecraftFreecam/Freecam)

- 允许相机脱离玩家并独立移动和旋转。
- 在自由相机活动期间保持真实玩家的位置不变。

### [CameraNoClip](https://github.com/Wurst-Imperium/CameraNoClip)

- 取消原版第三人称相机遇到方块时的距离收缩。

## 多视图与特殊投影

### [Immersive Portals](https://github.com/iPortalTeam/ImmersivePortalsMod)

- 渲染可以直接看见另一侧世界的传送门，并支持传送门嵌套渲染
- 客户端可以同时加载多个维度并同步远端世界中的方块和实体
- 传送门可以连接不同位置和维度，并改变穿过传送门的对象的尺度或重力方向

### [Vivecraft](https://github.com/Vivecraft/VivecraftMod)

- 使用 VR 头显和控制器提供沉浸式观察与操作
- 除头显视图外，还提供第一人称无畸变、第三人称和混合现实等桌面镜像模式，其中部分模式会增加额外渲染通道
- 第三人称和混合现实模式使用独立的观察相机；该相机可以固定放置，也可以通过控制器或追踪器移动和旋转
- 混合现实相机可以单独调整 FOV

## 相机状态的消费者

### 渲染器与光影模组

[Sodium](https://github.com/CaffeineMC/sodium) 替换 Minecraft 的世界渲染器以提高性能，[Iris](https://github.com/IrisShaders/Iris) 则增加光影包渲染。它们渲染相机所观察到的最终画面，但不提供玩家可选择的相机视角。

### 远景与区块渲染模组

[Distant Horizons](https://github.com/Distant-Horizons-Team/DistantHorizons) 和 [Voxy](https://github.com/MCRcortex/voxy) 使用 LOD 扩展远景渲染，[Bobby](https://github.com/Johni0702/bobby) 缓存服务器发送过的区块并在服务器视距之外显示它们。它们扩展相机可见的世界范围，但不提供玩家可选择的相机视角。
